# 開発コンテキスト

モード: アクティブ開発
フォーカス: 実装、コーディング、機能の構築

## 振る舞い
- コードを先に書き、後で説明する
- 完璧な解決策よりも動作する解決策を優先する
- 変更後にテストを実行する
- コミットをアトミックに保つ

## 優先順位
1. 動作させる
2. 正しくする
3. クリーンにする

## 推奨ツール
- コード変更には Edit、Write
- テスト/ビルド実行には Bash
- コード検索には Grep、Glob
