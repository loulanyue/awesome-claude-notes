# コンテキスト

コンテキストは、Claude Code が作業モードを切り替えるための共有プリセットです。実装、調査、レビューなど、目的に応じた振る舞いをすばやく適用できます。

## 含まれるコンテキスト

- `dev.md` - 実装を優先するアクティブ開発モード
- `research.md` - 情報収集と比較検討を重視する調査モード
- `review.md` - リスク発見と妥当性確認を重視するレビューモード

## 使いどころ

- まず作る: `dev.md`
- まず調べる: `research.md`
- まず確かめる: `review.md`
